◆ gcd_range()

template<typename I >

I  last 
)

Knuth, The Art of Computer Programming: Volume 2, Third edition, 1998 Chapter 4.5.2, Algorithm C: Greatest common divisor of n integers.

Knuth counts down from n to zero but we naturally go from first to last. We also return the termination position because it might be useful to know.

Partly by quirk, partly by design, this algorithm is defined for n = 1, because the gcd of {x} is x. It is not defined for n = 0.

テンプレート引数
IInput iterator.
戻り値
The gcd of the range and the iterator position at termination.
