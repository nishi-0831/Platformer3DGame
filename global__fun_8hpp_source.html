37/* global_fun is a read-only key extractor from Value based on a given global
38 * (or static member) function with signature:
39 *
40 * Type f([const] Value [&]);
41 *
42 * Additionally, global_fun and const_global_fun are overloaded to support
43 * referece_wrappers of Value and "chained pointers" to Value's. By chained
44 * pointer to T we mean a type P such that, given a p of Type P
45 * *...n...*x is convertible to T&, for some n>=1.
46 * Examples of chained pointers are raw and smart pointers, iterators and
47 * arbitrary combinations of these (vg. T** or unique_ptr<T*>.)
48 */
